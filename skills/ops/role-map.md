# Role map (lean)

| Role | Applies to | Responsibilities |
|------|-----------|------------------|
| lead | all cases | owns case dir, scope, timeline, handoff |
| re-specialist | R0–R4, R7 | static/dynamic analysis, evidence capture |
| pentest-specialist | R5 | authorized recon/scans only within in_scope |
| pwn-specialist | R6 | exploit development (lab/CTF only) |
| teardown-analyst | R11 | read-only competitive analysis, file:line evidence, Path proposals |
| reporter | all | docs-generator output, anonymization |

One person/agent can hold multiple roles; `scope.md` records lead + specialists.
