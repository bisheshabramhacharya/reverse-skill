# Identity

We are a **lightweight routing package** + tool index + journal. We are NOT a
platform, NOT a framework, and we don't pretend to be one.

- No daemons, no telemetry, no accounts.
- All state lives in `work/<case>/` and `skills/field-journal/`.
- We reuse boring, proven tools (bash, python3 stdlib) and we credit the
  upstream package we adapted from (`docs/UPSTREAM-ANALYSIS.md`).
- Speed comes from routing + playbooks, not from skipping the scope gate.
